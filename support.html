Questions fréquentes

Comment supprimer mon compte ?

Depuis l'appli, dans votre profil, ou en nous écrivant à Planteshop@icloud.com depuis l'adresse de votre compte. Vos données sont alors effacées dans les conditions prévues par notre politique de confidentialité.

Je ne reçois pas le code de connexion par email.

Vérifiez vos courriers indésirables, puis redemandez un code depuis l'appli. Si le problème continue, écrivez-nous.

Comment activer les paiements pour vendre ?

Dans l'appli, sur votre profil : « Activer les paiements ». L'inscription se fait avec notre partenaire Stripe, en quelques minutes.

Comment gérer mon abonnement ?

Les abonnements Pro et Business se gèrent dans les réglages de votre iPhone : Réglages › votre nom › Abonnements.
